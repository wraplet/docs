There are two possible approaches to rewrite the code. Top-down approach or bottom-up approach.

In the top-down approach, we start with an **impure** main wraplet and work our way down to the dependencies.
This approach is more suitable for more complicated code that has to be improved gradually.

In the bottom-up approach, we start with dependencies and work our way up to the main wraplet.
This is fine for a code that can be easily understood from the beginning and can be rewritten in a single step.
This works when we can easily identify the dependencies and their relationships.

On the "Examples" page you can read tutorials that show both approaches.
